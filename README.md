## 167ms 的延迟从哪来

这台机器国内 ping 大致在 167ms 上下。测评方公布的本地数据是 173ms，全国三网平均 167ms，电信 169ms，联通 167ms，移动 163ms，三家很接近。英国机房从国内直连通常在 200ms 以上，167ms 属于偏低的一档。

低在回程。三网回程走 CN2 GIA 直连回国，这一段是优化过的。去程没这么理想：三网都从北京出口出去，经德国节点转到伦敦机房，电信走 59.43 的 CN2、联通走 AS4837、移动走 CMI 骨干。上传方向绕了一段，下载方向才是那条优化线路。

这带来两个实际影响。从国内往服务器传文件，速度别按 500Mbps 去期待，测评方本地单线程下载测到 7.1MB/s（约 57Mbps），这个数字更多反映本地宽带和单线程的瓶颈，不代表端口上限。另外 167ms 是测评方所在城市的单点结果，你在广州、成都或者北方小城，数值会有出入，最稳的办法是先买一个月自己 ping 一遍。

这个延迟能干什么：SSH 敲命令不难受，网页后台、API 调用、抓取英国和欧洲站点都正常。实时对战类游戏别考虑，跨境视频会议也会有延迟感。

官网页面没有明确写 Windows 的支持情况。需要的话先开工单问，别默认可以。

**300Mbps 和 500Mbps 差得多吗？**
